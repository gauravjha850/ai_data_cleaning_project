# AI Data Cleaning Agent

AI-powered data cleaning platform with FastAPI backend, Streamlit frontend, and Groq AI integration.

## Features

- Upload CSV/Excel files
- AI-powered and rule-based cleaning
- EDA with interactive visualizations
- Feature engineering (polynomial, ratio, log features)
- Time series analysis (stationarity, ACF/PACF)
- Download cleaned data as CSV

## Tech Stack

- Python, FastAPI, Streamlit
- Groq AI (Llama 3.1)
- Pandas, Plotly, Scikit-learn

## Quick Start

```bash
pip install -r requirements.txt
python backend.py
streamlit run app.py
